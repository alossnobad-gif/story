## 已知边界

单工作室共享书架，无多账户、实时协作、完整版本历史、富文本、上传功能或永久删除。JSON 恢复仅替换当前作品；全书架需数据库备份。会话在内存中，服务重启需重新登录。离线不能保存，冲突时应导出未保存内容。无 AI Key 时显示固定示例，不是实时生成。真实 AI 需正确地域的密钥及网络访问，调用可能收费。

素材单文件最多 2 MB，总事件最多 2000 条；服务端请求体限制 8 MB。AI 上下文会截断，不能视为整部作品均已发送。历史单作品代码看不到书架后续编辑，不能作为无损降级方案。

构思草稿保存在作品 JSON 的可选 planning 字段中；无需新增数据库表。老备份仍可导入。构思一次只生成 1–12 章，不是整本小说自动写完；模型异常会保留输入及旧方案。生成正文按章审阅并追加，不替换已有正文。旧版软件可能丢弃规划字段，回退前必须做数据库与 JSON 备份。

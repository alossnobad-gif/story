# 关键回归检查

使用合成数据或隔离临时库；禁止拿生产库测试删除、迁移或恢复。每次交付区分自动通过、人工通过、失败、跳过和未运行。

## 自动检查

工作目录为仓库根目录，Node.js 24.5+ 的 24.x，依赖按 package-lock 安装。

```bash
npm test
npm run build
python3 -m unittest discover -s deploy -p 'test_*.py'
bash -n deploy/bootstrap.sh deploy/update.sh deploy/rollback.sh
```

Node 测试覆盖旧库迁移不重复且原记录保留、作品隔离、回收恢复、旧版本写入保护、状态校验、AI 上下文限制，以及密码登录/持久化/模拟服务商请求。Python 测试覆盖 WAL 一致性备份与源数据保留、备份权限，以及 HTTPS 版本和认证门禁（错误版本和无认证必须被拒绝）。它们不证明目标 ECS 的 systemd/Nginx 部署可用。

## 构思流程重点回归

- 打开作品默认进入构思；空想法不能调用真实生成，相对时间可输入，输入/方案与 JSON 备份持久化，旧备份仍兼容。
- API /api/plan 与其他业务接口共用登录和同源保护；拒绝空输入、超长内容、非法章节数；模型返回非 JSON/缺字段/数量不符时 502，旧稿与输入保持，锁必须释放可重试。
- 方案可改标题、时间、梗概；输入改变后旧方案不能采纳。采纳只追加，原正文不变，同一方案不能重复创建，不能突破 500 章限制。
- 跳转至采纳章节，根据梗概生成草稿，审阅后插入；同一结果不能重复插入。无梗概提示先填写。
- 无 Key 时显示固定示例与输入无关；采纳示例需明确确认，取消不创建章节。真实收费模型未经授权不调用。
- 桌面和手机检查输入、结果、错误和加载状态，无横向溢出或框架报错；保留书架/素材/角色入口。

## 本地功能与手动流程

- 启动 npm run server 与 npm run dev；检查后端 3001 和前端 5173 的首页、/api/health、/api/books，确认 Vite 代理实际可用。构建后后端应能提供 dist。
- 两部合成作品切换；正文、事件、角色不串书。新建、搜索、排序、改名、回收、恢复均正确；接近 200 部时核对限制。
- 输入正文等待自动保存，返回书架再打开；双窗口用旧 revision 保存应被拒绝，未保存稿可导出。断网不得显示保存成功。
- JSON/TXT/Markdown 素材导入正常及错误输入/超限；事件关联章节与角色上下文正确。
- 字体、字号、专注模式和导出可用；JSON 恢复前导出合成原稿，只替换当前作品，不影响其他作品。
- 无 Key 明确显示固定示例；有 Key 才验证真实生成、错误、超时及审阅后插入；不自动调用收费生产服务。
- 旧库迁移使用副本，验证内容与 revision 保留、重复启动不重复迁移、旧界面写入返回 409。

## 发布门禁

固定 SHA 的远程存在性、备份 quick_check、构建/测试退出码、服务 active、HTTP/HTTPS 精确 revision、首页、未登录书架 401、nature-photo active/PID 保持。用户另行确认公网登录、书架读写与实际 AI；本机 HTTP 成功不代表公网验收成功。记录至 RELEASES。
